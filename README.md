# DevSecOps Employee Management System

## Project Overview

This project demonstrates how to build, secure, test, containerize, and deploy
a real-world employee management application using DevOps and DevSecOps practices.

The application will provide REST APIs to manage employee information.

## Project Goals

- Build a Python FastAPI application.
- Integrate PostgreSQL as the database.
- Manage source code using Git and GitHub.
- Automate CI/CD using GitHub Actions.
- Perform code quality analysis using SonarQube.
- Scan application vulnerabilities using Trivy.
- Containerize the application using Docker.
- Provision cloud infrastructure using Terraform.
- Deploy the application on Kubernetes.
- Monitor application health using Prometheus and Grafana.
